# Ember

An example nest. Replace this with the agent's own words: who it is, what its job is, and how it got its name.

## The job is the skills

- `skills/<skill>`: a symlink to a skill in `~/.claude/skills/`. Link it, don't copy it, so every Claude shares the same skill.

## Waking up

1. `handoff.md`: where I left off.
2. `notes/`: what I've learned about the job.
3. `diary/`: the story, one file per day.

## Ending a session

Write today's diary entry (`diary/YYYY-MM-DD.md`, append if it exists) and rewrite `handoff.md`.
